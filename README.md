# Bilal Alaa Alsubah: maker portfolio

Live at **https://bilaljett.github.io**

## Updating it

All project content is in [`projects.js`](projects.js). The page builds itself from that file, so you never need to touch `index.html` to add a project or media.

- **Photos:** put them in `assets/img/` (JPEG, about 1400 px on the long side) and list them in the project's `images`. The first one is the main photo; a second one shows beside it.
- **Video:** paste a YouTube link into `video`. Unlisted YouTube videos work and keep the repo small. A short `.mp4` in `assets/video/` also works.
- **Code:** paste the repo link into `code` and a "View the code" link appears.
- **Results:** add short lines with numbers to `facts`.

Empty fields are hidden, so nothing half-finished ever shows on the live page.
